# AI-агент в Telegram для заработка (по мотивам Spru)

Бот делает «дела за пользователя» (поиск клиентов, цены, тексты, документы, напоминания)
и зарабатывает на подписке: 3 бесплатных запроса → paywall → Неделя / Месяц.

## Запуск

На сервере: см. [deploy.md](deploy.md) (Docker + автоматический https). Локально:
```bash
python -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env   # заполнить токены
python -m bot.main
```

## Деньги
1. @BotFather → Payments → подключить ЮKassa → токен в `PAYMENT_PROVIDER_TOKEN`.
2. Цены: `PRICE_WEEK_RUB`, `PRICE_MONTH_RUB`. `/stats` (для `ADMIN_ID`) — пользователи, подписчики, выручка.
3. Следите за себестоимостью: запрос с веб-поиском стоит заметно дороже обычного — подберите лимиты/цену.

## Mini App (меню, онбординг, оплата)
1. Задеплойте бота на сервер с публичным **https**-адресом (VPS + Caddy/nginx, порт `WEB_PORT`) и укажите его в `WEBAPP_URL`.
2. При старте бот сам поставит кнопку «Меню» в чате — она открывает Mini App.
3. Скидка новичкам (`DISCOUNT_PERCENT` на `DISCOUNT_HOURS` часов после первого /start) и таймер настоящие: цена в счёте считается на сервере.
4. Приветственная картинка: положите `assets/welcome.png` (необязательно).
5. Без `WEBAPP_URL` бот работает как обычный чат-бот с кнопками.

## Google Календарь
1. Google Cloud Console → OAuth client (Web), включить Calendar API, redirect URI `<WEBAPP_URL>/oauth/google/callback`.
2. `GOOGLE_CLIENT_ID` / `GOOGLE_CLIENT_SECRET` в `.env`. Пользователь подключается командой `/calendar`.
3. Запрашивается только доступ к событиям (`calendar.events`); напоминания дублируются в календарь.

## Что умеет агент (инструменты)
Claude сам решает, когда вызвать инструмент; показываются только настроенные:
- `remember` — память о пользователе (`/memory`, `/forget`); `set_reminder` — напоминания + Календарь
- `create_google_sheet`, `create_gmail_draft` — после `/calendar` (Gmail: только черновики, письма не отправляются)
- `instagram_profile` — `APIFY_TOKEN`; `edit_photo` — `REPLICATE_API_TOKEN`; `publish_site` — нужен `WEBAPP_URL`, ссылка вида `<WEBAPP_URL>/s/<slug>`
- голосовые — `OPENAI_API_KEY` (Whisper); выбор модели — `/model`
- задачи выполняются в фоне, бот отвечает, когда готово

## Подключение ЮKassa (пошагово)
1. В @BotFather: `/mybots` → ваш бот → **Payments** → **ЮKassa** → войти в аккаунт и подключить магазин.
2. Сначала выберите **тестовый** токен (вид `…:TEST:…`) → в `PAYMENT_PROVIDER_TOKEN`. Проверьте оплату тестовой картой, которую покажет BotFather. Затем подключите боевой токен.
3. Если в ЮKassa включена онлайн-касса (54-ФЗ), поставьте `YOOKASSA_RECEIPT=1` и настройте `YOOKASSA_VAT_CODE`, `YOOKASSA_TAX_SYSTEM` по данным вашего магазина; бот попросит e-mail для чека. Самозанятые обычно чеки через ЮKassa не включают — оставьте `0`. Налоговые настройки уточняйте у бухгалтера.
4. Платежи через Telegram + ЮKassa разовые (без автосписания) — для автопродления используйте Stars.

## Подписка
- Telegram Stars (`STARS_MONTH`): автопродление раз в 30 дней, отмена `/cancel` или в профиле Mini App.
- ЮKassa: разовые платежи на неделю/месяц (рекуррентов нет).
- Рефералы: `/invite`, бонус `REFERRAL_BONUS` обоим.

## Рестораны рядом
Сценарий «🍽 Ресторан рядом»: адрес текстом или кнопка «Отправить геопозицию». Порядок источников: 2ГИС → Яндекс Карты (`YANDEX_SEARCH_KEY`, геокодер `YANDEX_GEOCODER_KEY`) → OpenStreetMap; первый давший результат побеждает. 2ГИС Places API (нужен `DGIS_API_KEY`: рейтинг, отзывы, телефон, часы); если ключа нет или 2ГИС не ответил — OpenStreetMap (без ключей, но без рейтингов). **Проверьте лицензию 2ГИС:** тарифы, обязательное указание источника и запрет на хранение/массовый сбор контактов; демо-ключ — только для тестов. То же для Яндекса: бесплатный тариф «Поиска по организациям» — для некоммерческого использования, а лицензия может требовать показывать результаты на Яндекс Карте и запрещать хранение — **прочитайте условия до запуска платного бота**. Геопозиция хранится только в памяти процесса. Публичные серверы OSM имеют лимиты (≈1 запрос/сек), при росте нагрузки перейдите на платный геокодер/свой Overpass.

## Мастера рядом
Сценарий «🔧 Мастер на дом»: электрик, сантехник, мастер на все руки и т.п. по адресу или геопозиции. Тот же поиск (2ГИС → Яндекс → OSM); бот находит **компании и службы**, а не частных лиц, и сам ни с кем не связывается. В OSM покрыты лишь немногие ремесла (электрик, сантехник, плотник, кровельщик и др.) — для полноценного поиска услуг нужен ключ 2ГИС или Яндекса. В подсказках бота есть памятка о мошенниках и газе (104/112).

## Кино
Сценарий «🎬 Кино рядом»: ближайшие кинотеатры (карты) + афиша списком через веб-поиск со ссылками на источники. Время сеансов и цены бот называет только если нашёл на странице источника и всегда отправляет проверять на сайте кинотеатра; билеты не продаёт. Точные сеансы возможны только через партнёрский API билетного сервиса (подключается отдельно).

## n8n (внешние процессы)
Бот умеет запускать ваши процессы n8n по webhook (инструмент `run_workflow`). Права администратора и API-ключ n8n **не нужны**.
1. В n8n создайте процесс: узел **Webhook** (метод POST, *Respond: Using 'Respond to Webhook' node*) → ваши шаги → узел **Respond to Webhook** (вернуть текст или JSON).
2. Защита: в Webhook поставьте **Authentication → Header Auth**, имя заголовка `X-Bot-Secret`, значение — длинный случайный секрет.
3. Включите процесс (**Active**) и возьмите **Production URL** (не Test URL).
4. В настройках бота (EasyPanel → Environment) задайте `N8N_SECRET` (тот же секрет) и `N8N_WEBHOOKS`, например:
   `{"avito_publish":{"url":"https://<n8n>/webhook/abc","description":"Опубликовать объявление: title, price, text","confirm":true}}`
   `confirm: true` — бот сначала покажет пользователю, что будет сделано, и вызовет процесс только после явного «да».
5. Тело запроса: `{"user_id": <id>, "payload": {…}}`. Для долгих процессов (>50 сек) верните ответ сразу, а результат пришлите на `POST <WEBAPP_URL>/api/n8n/callback` с заголовком `X-Bot-Secret` и телом `{"user_id": <id>, "text": "…"}`.
6. Ключи внешних сервисов (Авито и т.п.) храните в Credentials n8n, не в боте. Если n8n и бот в одной сети EasyPanel, можно использовать внутренний адрес сервиса вместо публичного.

## Лимиты и докупка
- Подписка включает пакет запросов: `CREDITS_MONTH` (150) / `CREDITS_WEEK` (40); каждое продление Stars добавляет новый пакет.
- Обычный запрос стоит 1, анализ Instagram — 2, правка фото — 3. Остаток: `/balance` и вкладка «Профиль».
- Когда пакет закончился, бот предлагает докупить `TOPUP_CREDITS` запросов за `TOPUP_RUB` ₽ или `TOPUP_STARS` ⭐ (только при активной подписке). Неиспользованные запросы не сгорают.
- **Заложите маржу:** замерьте реальную стоимость запроса в Anthropic и подберите цены так, чтобы пакет подписки и докупка были прибыльны с запасом (особенно запросы с веб-поиском).
