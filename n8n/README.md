# Шаблоны процессов n8n

Импорт: n8n → **Workflows → ⋯ → Import from file** → выберите JSON.
Перед включением: создайте Credential **Header Auth** с именем `Bot secret` (Name = `X-Bot-Secret`, Value = ваш `N8N_SECRET`)
и выберите его в узлах Webhook (и «Callback в бота»). Затем включите процесс (**Active**) и скопируйте **Production URL**.

| Файл | Что делает | Запись в `N8N_WEBHOOKS` |
|---|---|---|
| `bot-ping.json` | Проверка связи: возвращает `pong` и принятые поля | `"ping":{"url":"<Production URL>","description":"Проверка связи, поле text"}` |
| `bot-async.json` | Отвечает сразу, через 10 с шлёт сообщение в чат пользователя через `/api/n8n/callback` — основа для долгих задач | `"async_demo":{"url":"<Production URL>","description":"Тестовая долгая задача"}` |

В `bot-async.json` замените `https://ВАШ-ДОМЕН` на адрес бота (`WEBAPP_URL`). Шаблоны сделаны по документации n8n и не проверялись
на вашей версии: если узел пишет об ошибке параметров, откройте его и выберите значения вручную (структура остаётся прежней).
Проверка: напишите боту «запусти ping с текстом привет» — в ответе должно быть `pong`.
